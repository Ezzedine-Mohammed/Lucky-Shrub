# Lucky Shrub 🌿

A responsive homepage for **Lucky Shrub**, a fictional garden design and plant nursery business in Tucson, Arizona.

I built this project as part of Meta's **HTML and CSS in Depth** course on Coursera, within the Meta Front-End Developer Professional Certificate. It brings together semantic HTML, responsive layouts, and visual styling in a single-page website.

**[View the live demo](https://ezzedine-mohammed.github.io/Lucky-Shrub/)**

## About the project

The page introduces the business through a promotional hero section and three service cards:

- Garden design and creation
- Maintenance and landscaping
- Indoor and outdoor plants

A navigation bar links to the page sections, and the footer includes social links. This is an educational front-end project; the business and promotional offer are part of the fictional brief.

## Implementation highlights

- **Semantic HTML:** page structure built with `header`, `nav`, `main`, `section`, `article`, and `footer`.
- **Responsive layouts:** CSS Grid for the overall page structure, Flexbox for content sections, and media queries to adjust layouts for smaller and larger screens.
- **CSS organization:** custom properties for colors and native CSS nesting to group related rules.
- **Visual details:** a garden-inspired color palette, Montserrat typography, and link hover states.
- **Accessibility details:** alternative text for images and visible keyboard focus styles on navigation and social links.

## Technologies

- HTML
- CSS
- Font Awesome for social icons
- Google Fonts for the Montserrat typeface
- GitHub Pages for hosting

The page uses no JavaScript and requires no package installation or build step.

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/Ezzedine-Mohammed/Lucky-Shrub.git
   cd Lucky-Shrub
   ```

2. Open `index.html` in your browser, or serve the folder with a local development server such as VS Code Live Server.

Use a modern browser that supports native CSS nesting. An internet connection is needed to load Montserrat from Google Fonts; the page uses a fallback font if it is unavailable.

## Project structure

| Path | Purpose |
| --- | --- |
| `index.html` | Page content and semantic structure |
| `style.css` | Layout, colors, responsive rules, and interaction styles |
| `all.min.css` | Font Awesome stylesheet |
